my main project

auth's RNG

A browser-based incremental game built almost entirely from scratch, and the project I've lived in for a long minute!

It began as a RNG mechanic to one of my hobby ISS tracker sites, which my friend liked, and then transformed into a full game. It uses it's own RNG engine, has it's own database and backend, accounts, backups, a lot more than you'd expect from a gambling-esque web game!

Play it: authsrng.xyz >> Source on GitHub >> Join the Discord server for it >>
